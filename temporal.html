Temporal Engine

Deterministic time simulation. Seeded runs, fixed kernels, no network. The same input produces the same future.

Engines

Simulationsim.logistic · sim.predator · sim.epidemic · sim.wave
ForecastProject a kernel 1–12 steps with a confidence band that widens with horizon.
ScenarioTwo states, same horizon. Reports drift and whether the pair converges or diverges.
ReplayRe-run a recorded seed. Output is byte-identical; any difference is a bug, not noise.

Limits

Every parameter is clamped, every run is capped at 12 steps, and a missing seed is filled from the clock and then reported. The engine models state change over simulated time; it does not move, rewind or observe the real world.
