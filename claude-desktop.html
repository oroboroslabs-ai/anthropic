Windows + Linux

Windows ships an NSIS installer and a portable .exe that runs from anywhere. Linux builds an AppImage and a .deb with one script.

$OA Claude AI Desktop Setup 1.5.5.exe
$OA Claude AI Desktop 1.5.5.exe
$./scripts/build-linux.sh

SmartScreen warns because the binary is unsigned. More info → Run anyway. Signing needs a code-signing certificate.

config.json — every app and folder

One map for the whole drawer. Add a row, restart, done — no rebuild for a config change when running from source.

›app:worldfeed → http://127.0.0.1:8100
›app:q5 → http://127.0.0.1:8101
›folder:skills → ~/.agents/skills

Failure is quiet

A row that cannot answer prints a quiet line at the bottom of the window — not reachable — … — instead of failing silently. Nothing crashes when a service is down.
