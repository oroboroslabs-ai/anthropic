✦ operations manual · the totalcontrol line

How it operates exactly.

Every surface of TotalControl — the harness, the hands session, the extension relay, the weights, the memory, the crawler and the wallpaper — runs on one vocabulary and one law: local-only, weights retrieved — never embedded, and the loop = models only.

gateway local-only 127.0.0.1weights never embedded — retrieved the loop = models onlyone hands vocabulary

The flow, end to end.

1 · THE MODEL

A model runs where you installed it — Ollama, a HF safetensors body, LM Studio, or any root your machine carries. The static weight core does not load weights into the model; it retrieves their composition — bodies, tensors, shards — so the model treats them as its own mass while the files stay untouched on disk.

2 · THE LOOP

The loop is the model's data line: a job of steps (tools) — echo, weights.* (bodies, resolve, verify, load, loaded, assure), doc.read, memory.* (put, get, search), file.insert, hands.intent, hands.extract_form, hands.read, cordis.*, orca.call, wallpaper.* — executes step by step and results stream back. Models only: every job needs the loop token.

3 · THE HANDS (browser control)

One intent vocabulary on every surface: url_bar / open (surf + page changes), extract_form (reads every fillable field with its selector), fill_form (enters the user's data — typed from text or voice — into the right fields), type_text (real keystrokes, keydown → input → keyup), click / move (the arms: pointer motion, grip, press), read_text (reads the page back), choose / check, back / forward / reload, scroll, wait, observe.

Routing: the live hands session (the harness's own browser at 8792) drives first; when no session is open, the EXTENSION RELAY carries the same intent to every armed browser page and the percept streams back through the relay. Same words, same percepts, either route.

4 · THE EXTENSION RELAY

The pro extension (Chrome / Edge / Firefox) connects to ws://127.0.0.1:8792/relay, registers as extension, and answers intents with percepts. The panel's relay card counts armed extensions; intents without an armed page return no extension armed — an honest error, never a silent hang.

5 · MEMORY (internal RAG)

Everything inserted — pasted text, markdown, PDFs, images — is chunked and embedded through the local Ollama (nomic-embed-text) on the fly. Recall is hybrid: 75% semantic + 25% keyword, over the passages. If the embedder is unavailable, recall degrades to keyword and never dies. It is internal to the build: no external service, nothing cloud, nothing proprietary.

6 · DOC FEED + CRAWL SURFACE (8789 crawler side)

The crawler page carries its own menus (design, units) and its own WALLPAPER menu — a covered scroll-down inside DOC FEED — CRAWL SURFACE: show/hide, image (URL, path, or from file), blur, frosted-glass translucency, reset. The darkening layer was removed: frost only rides an image that is actually applied. The shared relay state stays clean (alpha 0) unless a panel publishes it.

7 · THE WALLPAPER

Wallpaper belongs to the main panel and rides the session: one source publishes it, the crawler surfaces follow, and the hands session's own pages carry it too. No blanket wash — the studio color stays if no image is set.

Install — no signing, no accounts.

Free core

Download TotalControl-Free-Core.zip → unpack → Python 3.13 → py -3.13 -m venv .venv → pip install -r requirements-core.txt → START-CORE.cmd → the panel at 127.0.0.1:8792/core. The free build: no hands, no extension, no crawler, no memory — law, not config.

Pro (Core Hands)

TotalControl-Hands-Pro zip + the extensions addon. The hands gateway binds 127.0.0.1:8792/ (one server at a time; the free core shares the port). Load the extension unpacked per browser (developer mode), point OPTIONS at the relay, arm.

Operations checklist.

  • GET /api/health — service, version, extensions armed, counters.
  • GET /api/session/state — session live, url, title, relay counts, wallpaper.
  • GET /api/weights/assure — full type·size assurance verdict over every loaded system.
  • GET /api/weights/verify — file-level connections + measured mass.
  • POST /api/memory/insert-file — documents/pdf/images in; key = the file's name.
  • GET /api/memory/search?q=… — hybrid semantic + keyword recall.
  • The drive proof: /test/form-test.html — the hands navigate, read fields, fill, submit, and read the confirmation back — end to end.
