Install

Install from source

Clone the full source and install with pip.

$git clone https://github.com/oroboroslabs-ai/claude-cli
$pip install -r requirements.txt
$pip install -e .

Then run claude-cli

Starts the glass UI at http://127.0.0.1:5000 and terminal coding chat. Not Anthropic's claude (Claude Code).

$claude-cli

Windows one-click launcher: start_claude_cli.bat
