Where the layer lives.

Verify Docker before anything

All three must succeed. If hello-world fails, the engine is not running.

$docker --version
$docker compose version
$docker run --rm hello-world

Bring the stack up

Each layer waits for health before the next.

$docker compose up -d redis
$docker compose up -d rune-engine core
$docker compose up -d ring-01 ... ring-12
127.0.0.1 publishes only rings have no host port compose fails loudly on a taken port oroboros labs · all rights reserved
Troubleshooting — the four that actually happen

command not found — open a new terminal. cannot connect to the daemon — start Docker Desktop. port already allocated — docker ps and stop the container holding it. volume mount denied — Settings → Resources → File sharing.
